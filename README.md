# Student-Grade-Tracker-C

🎓 Student Grade Tracker in C

A simple console-based Student Grade Tracker developed in C. This project allows users to manage student records, calculate average marks, determine grades, and generate report cards through a menu-driven interface while demonstrating fundamental C programming concepts.

✨ Features

👨‍🎓 Add Student Details

📝 Enter Subject Marks

📊 Calculate Average Marks

🏆 Grade Calculation

📄 Generate Report Card

🚪 Exit Option

🛠️ Technologies Used
C Programming Language
Visual Studio Code
GCC Compiler

📂 Project Structure

Student-Grade-Tracker-C/
│── main.c
│── README.md

🚀 How to Run

Clone the repository:
git clone https://github.com/tushargautam-dev/Student-Grade-Tracker-C.git
Open the project in VS Code.

Compile the program:

gcc main.c -o student
Run the executable:
./student
For Windows:

student.exe
